# omiiko-eigo

学習塾omiiko の英語教材リポジトリ。教材はすべて **外部依存のない単一HTMLファイル** で、ブラウザで開くだけで動きます。

## 公開ページ

GitHub Pages で公開しています（Settings → Pages / Branch: `main` / Folder: `/ (root)`）。

## 収録教材

| 教材 | 出典 | 内容 |
| --- | --- | --- |
| [`food-on-the-rails.html`](food-on-the-rails.html) | Jeri Quinzio, *Food on the Rails* (2014) | 英語長文精読ノート「イギリスの鉄道と『駅の軽食堂』」。約840語／語彙109項目／全訳／設問6問（自動採点）／構文メモ16点 |
| [`be-up-to.html`](be-up-to.html) | The Boy Who Harnessed the Wind (Lesson 12) | 英文法ノート「be up to・now・否定＋比較」。5タブ構成／例文／確認テスト |

## 構成ルール

- 教材は1ファイル完結（CSS・JSはインライン、外部CDNなし）。オフラインでも動く。
- 教材はリポジトリ直下に置く（ファイル名で内容がわかるように）。
- 教材を追加したら `index.html` にカードを1つ足す。
- ブラウザの印刷機能で、訳・解答・語義をすべて開いた状態のPDFになるよう印刷用CSSを入れてある。

## ライセンス・引用について

各教材の英文は出典に記載の著作物からの引用であり、塾内での学習用途を想定しています。
